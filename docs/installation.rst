Instalación
============

Requisitos Previos
------------------

Para ejecutar esta aplicación, necesitas tener instalado Python (se recomienda la versión 3.10 o superior).

Instalación de Dependencias
---------------------------

1. Clona el repositorio o descarga el código fuente.
2. Abre una terminal en la carpeta principal del proyecto.
3. Instala las librerías necesarias ejecutando:

.. code-block:: bash

   pip install -r requirements.txt
