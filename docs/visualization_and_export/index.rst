Visualization & Publication Tools
==================================

Extracting physical insights and sharing scientific results requires high-fidelity, publication-quality graphics. SPARK provides interactive data exploration windows and dedicated publication-grade figure designers.

Features at a Glance
--------------------

* **Interactive Trace Explorer**: Dual-panel viewer (linear & logarithmic time scales) showing experimental data, total global fit, and isolated contributions of each kinetic component.
* **3D Surface Viewer**: Perspective 3D rendering of transient matrices with wall-projected marginal slices and symlog elevation scaling.
* **PaperPlotter (Kinetics)**: Standalone drag-and-drop kinetics figure designer with Nature/Viridis palettes, error bars, and 600 DPI vector/raster export.
* **SASDASPlotter (Spectra)**: Standalone spectra figure designer for DAS and SAS plots with publication font controls and error bar styling.
* **Automated Multi-Page PDF Reports**: Comprehensive multi-page PDF generation summarizing experimental conditions, model topology, parameter tables, identifiability audits, correlation matrices, and 2D triplet maps.
